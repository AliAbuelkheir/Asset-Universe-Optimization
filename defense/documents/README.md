# Defense Documents

- `defense_revision_roadmap.md` is the canonical slide, script, diagram,
  study, rehearsal, and Q&A checklist. It is also the progress tracker.
- `defense_slide_guide.md` is the concise slide-by-slide reference generated from the current deck.

Do not create competing TODO files, slide maps, or extracted deck snapshots. Run `$update-defense-docs` after the deck changes, and mark completed roadmap items with `[x]`.
